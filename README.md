### 🚀 Featured Project: Enterprise School Management SaaS (MVP)
A production-ready, full-stack school management system designed to handle users, courses, class sessions, and enrollments. Inspired by direct feedback from students and employees at a local language school to address real-world administrative pain points.

* **Status:** **Active MVP** (Core architecture, user routing, and data layer fully operational; actively iterating on extended feature roadmap).
* **Repository:** [ThomasParratt/school-system](https://github.com/ThomasParratt/school-system)
* **The Architecture:** Single Page Application built with **Vite + React** paired with a **Node.js** REST API backend.
* **Data Layer:** Relational schema designed in **PostgreSQL** with role-based dashboard access control spanning three distinct account archetypes (Administrators, Instructors, and Students).
* **API Standards:** Entirely architected and documented using **OpenAPI Specification** for contract-first reliability.
* **DevOps & CI/CD:** Fully containerized using **Docker Compose** for environment parity. Automated via **GitHub Actions** to execute a **Vitest** testing suite prior to direct deployment on **AWS**.
